================================================================
 单周期 CPU 设计参考（8 条指令）
================================================================

写代码的时候把这份文件开着，省得反复回翻。


----------------------------------------------------------------
 一、指令编码
----------------------------------------------------------------
R 型：op = 000000，格式 {op[31:26], rs[25:21], rt[20:16],
                          rd[15:11], shamt[10:6], funct[5:0]}

    指令      funct
    add       100000   (0x20)
    sub       100010   (0x22)
    and       100100   (0x24)
    or        100101   (0x25)
    slt       101010   (0x2a)

I 型：格式 {op[31:26], rs[25:21], rt[20:16], imm[15:0]}

    指令      op
    lw        100011   (0x23)
    sw        101011   (0x2b)
    beq       000100   (0x04)

立即数一律 16 位符号扩展。beq 的 imm 是"指令条数"偏移，
算目标地址时要先左移 2 位变成字节数。


----------------------------------------------------------------
 二、模块清单
----------------------------------------------------------------
文件              职责                        关键点
--------------------------------------------------------------------
rtl/pc.v          32 位 PC 寄存器             同步复位，pc <= pc_next
rtl/imem.v        指令存储器(256 字)         组合读，索引 addr[9:2]
rtl/regfile.v     32x32 寄存器堆              两读一写，$zero 恒 0
rtl/signext.v     16 -> 32 符号扩展           {{16{imm[15]}}, imm}
rtl/alu.v         5 种运算 + zero              slt 必须用 $signed
rtl/alucontrol.v  ALUOp + funct -> ALUControl  两级译码
rtl/control.v     opcode -> 8 个控制信号       主译码器
rtl/dmem.v        数据存储器(256 字)          组合读，上升沿写
rtl/datapath.v    数据通路 + ALU 控制          只做连线，时序块只有
                                              PC 和 regfile 写口
rtl/cpu_top.v     datapath + control           对外只有 clk / rst


----------------------------------------------------------------
 三、控制信号真值表
----------------------------------------------------------------
指令    RegDst  ALUSrc  MemToReg  RegWrite  MemRead  MemWrite  Branch  ALUOp
--------------------------------------------------------------------------
R 型       1       0        0         1        0        0         0      10
lw         0       1        1         1        1        0         0      00
sw         X       1        X         0        0        1         0      00
beq        X       0        X         0        0        0         1      01

ALUOp 编码：  00 = 做加法（算地址）
              01 = 做减法（beq 比较）
              10 = 看 funct 决定

X 表示这条指令用不到，写 0 也可以。

PCSrc = Branch & Zero


----------------------------------------------------------------
 四、ALUControl 真值表
----------------------------------------------------------------
ALUOp  funct     ALUControl   运算
------------------------------------------------------------------
00     xxxxxx    0010         a + b
01     xxxxxx    0110         a - b
10     100000    0010         a + b        (add)
10     100010    0110         a - b        (sub)
10     100100    0000         a & b        (and)
10     100101    0001         a | b        (or)
10     101010    0111         a < b ? 1:0  (slt，有符号)

其余组合随便给 0000 或 x，反正不会出现。


----------------------------------------------------------------
 五、数据通路关键连线
----------------------------------------------------------------
这几条先写下来再动手，能省一半调试时间：

    pc_plus4 = pc + 4
    wr_addr  = RegDst  ? rd   : rt
    alu_b    = ALUSrc  ? imm32 : rf_rd2
    wr_data  = MemToReg ? dmem_rdata : alu_result
    pc_next  = PCSrc   ? (pc_plus4 + (imm32 << 2)) : pc_plus4

注意 Branch 的目标基址是 pc_plus4，不是 pc。
注意 alu_a 永远接 rf_rd1，只有 alu_b 需要 mux。


----------------------------------------------------------------
 六、六个最容易踩的坑
----------------------------------------------------------------
1) slt 要有符号比较
   result = ($signed(a) < $signed(b)) ? 32'd1 : 32'd0;
   用无符号比的话 -1 < 1 会算成假，而且只在负数用例上才暴露。
   tb_alu.v 里有专门的这条用例。

2) beq 的目标基址是 PC+4
   pc_plus4 + (imm32 << 2)。写成 PC 的话，如果测试程序凑巧
   差一条指令，你会以为它是对的，然后在别的地方怀疑人生。

3) sub 别忘了 +1
   a - b = a + ~b + 1，漏了进位输入会差 1，
   看起来像是"ALU 偶尔算错"。

4) $zero 要硬保护
   写口加 rd != 0 条件；读的时候也要保证读出来是 0。
   别指望"没人会写它"。

5) 没有 addi，循环怎么自增
   把常数 1 预置进 DMEM，用 lw 读进寄存器，再用 add 加。
   test/prog2.asm 就是现成范例。

6) 没有停机指令
   约定 .halt = beq $zero, $zero, -1，原地自旋。
   tb 检测到 PC 连续两拍不变就认为程序结束。
   （imm = 0xFFFF 符号扩展后左移 2 位是 -4，
     所以 PC+4-4 正好回到自己）


----------------------------------------------------------------
 七、调试习惯
----------------------------------------------------------------
* 先只跑通 add 一条指令。端到端通了，再一条一条加。

* 每次 make sim 先看 PASS/FAIL 那几行，再去翻波形。
  自检挂了但 PASS 了，说明你的 .expect 写错了，不是 CPU 的错。

* gtkwave 里常看的信号：
    pc / instr / alu_result / wr_data / dmem 的写使能
  把这几根加进波形存成 .gtkw，下次直接打开，省 5 分钟。

* 信号是 x，先查"有没有赋值"，再查"算得对不对"。
  新人 90% 的 x 是漏连了一根线。

* iverilog -Wall 的 warning 要看。尤其是
  "implicit wire" 和 "port size mismatch"，这两个几乎必出 bug。
